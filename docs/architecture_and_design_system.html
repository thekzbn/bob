src/common.h Memory Management & Dynamic Buffer Subsystem

Defines standardized, failure-aborting heap allocation routines and the StringBuilder dynamic buffer abstraction used throughout lexing, parsing, and code generation.

Structures

  • StringBuilder: Dynamic heap buffer with char *data, size_t length, and size_t capacity, self-doubling when capacity is reached.

src/lexer.h & src/lexer.c Line-Aware Lexical Tokenizer

Transforms raw UTF-8 source strings into a stream of structured Token instances. Preserves newlines as structural tokens (since Bob is line-based) while collapsing non-semantic consecutive blank lines.

Structures & Enumerations

  • TokenType: Enum covering literal strings, multi-line triple strings ("""), font names, numbers, hex colors, brackets ([, ]), dots (.), block arrows (make-->, <--, ->), and keywords (when, click, if, whisper, yell, tell, show, hide, read, smooth, page, all, add_class, remove_class, toggle_class, js).
  • Token: Holds TokenType type, char *text, int line, and int col.
  • Lexer: Cursor containing const char *source, size_t pos, int line, and int col. Supports dashed identifier lexing for attributes (e.g. aria-label, data-theme).

src/ast.h & src/ast.c Abstract Syntax Tree Data Models & Lifecycle

Declares the hierarchical node models representing Bob programs, including expressions, element declarations with nested child lists, styling modifiers, and control flow blocks.

Structures

  • Expr: Expression node supporting uninitialized zero (0), numbers (including 00 numeric zero flag), string literals, multi-line triple strings, variable references, binary operations, assignments, read <target> calls, and JavaScript interop expressions (EXPR_JS).
  • Attribute: Key-value pair with optional value and boolean attribute flag for general HTML element attributes.
  • StyleModifiers: Stores alignment (center, left, right), text color, background color, font family, font size in rem, bold, italic, and hide flags.
  • BobElement: DOM node holding tag name, optional custom ID, automatic ID, content expression, styling modifiers, dynamic list of Attributes, is_svg flag, and a dynamic array of child BobElement* pointers for Rule C and block nesting.
  • Stmt: Statement union supporting variable assignments, global page/all styling, element creation, element mutation, console output, alerts, show/hide, smooth transitions, conditionals, event listeners, class styles (.card: ...), class mutations (add_class, remove_class, toggle_class), and JavaScript statements/blocks (STMT_JS_STMT).
  • Program: Top-level program representation containing an array of Stmt* statements.

Memory Lifecycle and Ownership Architecture

The Bob compiler enforces a clean allocation ownership hierarchy to ensure zero leaks across compilation:

  • Source Buffer: Read once by main.c, retained as read-only buffer by the lexer, and freed at the conclusion of main.
  • Token Life: Tokens are created by lexer_next_token with allocated text strings. The parser immediately takes ownership and frees consumed tokens via token_free.
  • AST Ownership: Nodes created by expr_create_*, element_create, and stmt_create are owned by their enclosing parent nodes. Calling program_free(prog) recursively frees all AST nodes and string properties.
  • Metadata Lifecycle: The MetadataRegistry lives throughout the compilation pass and is written to disk via meta_save before being freed by meta_free.
