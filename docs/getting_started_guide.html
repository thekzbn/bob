Getting Started with Bob

A walkthrough for compiling the Bob compiler, initializing your first web document, and creating interactive components.

Installation Options

Bob can be installed directly through npm with pre-compiled native binaries for macOS, Linux, and Windows, or built locally from its C11 source code.

1. Via npm (Recommended)

No C compiler, Xcode tools, or make setup required. Works out of the box on macOS (Apple Silicon and Intel), Linux, and Windows: 

npm install -g bob-lang

Once installed, compile any Bob document with bobc: 

bobc app.bob -o dist/index.html

You can also run one-shot compilations without installing globally via npx: 

npx bob-lang app.bob -o dist/index.html

2. Building from Source

The Bob compiler source in src/ has zero third-party dependencies beyond standard C11 libraries and can be compiled using GCC or Clang: 

gcc -Wall -Wextra -std=c11 -O2 src/lexer.c src/ast.c src/parser.c src/meta.c src/id_gen.c src/codegen.c src/main.c -o bobc.exe

Confirm the binary runs: 

./bobc.exe --version
# bobc version 0.1.0 (esoteric web compiler)

Project Initialization

Bob does not use package managers, configuration files, or build artifacts. A project begins with a single .bob source file: 

mkdir site
cd site
touch app.bob

A Complete Reactive Document

Here is a functional application written in app.bob. It establishes variables, applies global styling, creates an inline nested structure, registers event listeners, and coordinates transitions: 

// 1. Declare state variables
visitor_name = 0
is_active = 00

// 2. Global page styling
page: bg #0e0d0c #f0ede6 'Inter'

// 3. Inline parent-child nesting (Rule C)
center div(portal): h1: "Bob Portal" #f0ede6 2.2, tell: "Enter your handle to register." 1.0

// 4. Interactive controls
center input(handle_input): "Your username..." #0e0d0c bg #f0ede6 1.0 hide
center button(action_btn): "Get Started" #f0ede6 bg #1e90ff 1.1

// 5. Transition directive
smooth text -> portal 0.4

// 6. Reactive event listener
when click(action_btn) make-->
    if is_active = 00 make-->
        show handle_input
        action_btn: "Confirm Username"
        is_active = 1
    or else-->
        visitor_name = read handle_input
        if visitor_name = "" make-->
            portal: "Please provide a valid name."
        or else-->
            portal: "Welcome aboard, " + visitor_name + "."
            hide handle_input
            hide action_btn
        <--
    <--
<--

1. Variables (0 vs 00)

      

        Bob distinguishes between uninitialized state and numeric zero:
      

      
    
        
  • visitor_name = 0 sets the variable to uninitialized (compiled to undefined).
    • 
        
  • is_active = 00 explicitly sets the variable to numeric 0.

2. Anatomy of the Colon

      

        In center div(portal): ..., the colon acts as a spatial boundary:
      

      
    
        
  • Tokens to the left of the colon configure the container (such as center layout).
    • 
        
  • Tokens to the right of the colon define content, text colors, background colors, and typography.
    • 
      


      
3. Rule C: Inline Child Nesting

      

        The comma separates direct children within a parent:
      

      
center div(portal): h1: "Bob Portal", tell: "Subtitle"

      

        The line boundary terminates the parent element. Elements declared on the subsequent line are siblings outside the container.

Compilation Targets


      
Single-File HTML Output (Default)

      

        To produce a standalone HTML file with embedded CSS and runtime:
      

      
./bobc.exe app.bob -o dist/index.html

      

        The generated file requires no server and functions when opened directly from the filesystem.
      


      
Split-File Output

      

        If separate files are needed for web servers:
      

      
./bobc.exe app.bob --split dist/

      

        This emits dist/index.html, dist/style.css, and dist/script.js.
