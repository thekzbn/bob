# AGENTS.md

## Commit Message Guidelines

All commits in this repository must strictly adhere to the following structure:

### Commit Title Format
```
<thing>(scope): summary of changes and why
```
Where `<thing>` is a semantic type (e.g. `feat`, `fix`, `docs`, `test`, `refactor`, `chore`).

### Commit Description Format
```
Reason for changes:
Generous description of the reason for changes.

What was changed:
- List of all the stuff that was changed and what exactly was changed
```

## Design and Development Principles
* Bob is an esoteric web development language that compiles directly into standard HTML, CSS, and JavaScript.
* Preserve previously established Bob syntax, ID generator stability, and nesting semantics.
* Avoid top navigation bars, keep 1px subtle borders, and use `#1e90ff` (Dodger Blue) as the primary accent color.
* Avoid em dashes in all code and documentation.
